One office-life joke in one line (130 characters): a deadline moved two weeks earlier to create urgency ends up due three days before the client sends the brief. The program writes that single line to /output/entry.txt. Ten candidates were written for this entry and ranked in a strict external review against the judge's published brief (true office observation first, then a surprising turn, tightness and originality); the deadline-escalation line won, and the review's one tightening cut was applied by deletion only.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
